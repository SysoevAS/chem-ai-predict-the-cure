# ChemAI: Predict the Cure

## О проекте

Проект выполнен в рамках хакатона **ChemAI: Predict the Cure**.

Задача соревнования - по молекулярным дескрипторам химических соединений предсказать три показателя биологической активности:

- `IC50` - концентрация, при которой вещество подавляет 50% активности вируса;
- `CC50` - концентрация, при которой вещество токсично для 50% клеток;
- `SI` - индекс селективности.

Данные состоят из числовых признаков, описывающих физико-химические, структурные и электронные свойства молекул. Основная метрика соревнования - RMSE на предсказаниях трёх целевых переменных.

## Краткое описание решения

Сначала команда построила baseline-модели и получила первые рабочие submission. После анализа результатов стало понятно, что самый сложный target - `SI`, потому что он имеет сильные выбросы и нестабильное распределение.

На этапе EDA была подтверждена важная связь:

```text
SI = CC50 / IC50
```

Поэтому финальная стратегия строилась не только на прямом предсказании `SI`, но и на использовании этой формулы через аккуратное смешивание модельного и формульного предсказания.

После стабилизации `SI` команда улучшала `IC50` и `CC50` через target-wise stack и adversarial weighted overlay. При этом `SI` на финальном этапе не пересчитывался заново, потому что эксперименты показали, что сохранение уже стабилизированной версии даёт более устойчивый результат.

Финальная логика:

```text
IC50 = 0.80 * base_IC50 + 0.20 * adv_IC50
CC50 = 0.70 * base_CC50 + 0.30 * adv_CC50
SI = base_SI
```

Где `base_SI` - стабилизированная версия, полученная через смешивание отдельной SI-модели и формулы `CC50 / IC50`.

## Как воспроизвести

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Положить данные в папку `data/`.

3. Запустить ноутбуки:

```text
notebooks/01_eda.ipynb
notebooks/04_final_pipeline.ipynb
```

4. Финальный submission сохраняется в папку `submissions/`.

# Итоговое описание решения

## Задача

В рамках хакатона ChemAI: Predict the Cure нужно было построить pipeline для предсказания трёх показателей биологической активности химических соединений:

- `IC50` - концентрация, при которой вещество подавляет 50% активности вируса;
- `CC50` - концентрация, при которой вещество токсично для 50% клеток;
- `SI` - индекс селективности.

Данные представлены числовыми молекулярными дескрипторами. Основная сложность задачи заключалась в небольшом размере обучающей выборки и нестабильности таргета `SI`, который имеет сильный хвост и связан с `IC50` и `CC50`.

---

## Общая стратегия

Мы не строили решение вокруг одной модели. Вместо этого работа шла поэтапно:

1. Первичный анализ данных и проверка признаков.
2. Построение baseline-моделей.
3. Отдельная работа с `SI`.
4. Использование связи `SI = CC50 / IC50`.
5. Target-wise stack для `IC50` и `CC50`.
6. Небольшие overlay поверх сильной базовой версии.
7. Финальный выбор submission по Kaggle score и устойчивости распределений.

Главный принцип: каждое изменение проверялось не только по leaderboard, но и по смыслу распределений предсказаний.

---

## Что показал EDA

На этапе анализа данных мы нашли несколько важных особенностей:

- train содержит 751 объект;
- test содержит 250 объектов;
- все признаки числовые;
- были найдены константные и почти константные признаки;
- `SI` имеет сильные выбросы;
- `SI` практически задаётся формулой `CC50 / IC50`.

Именно связь `SI = CC50 / IC50` стала одной из главных идей финального решения.

---

## Baseline

Первые модели строились на стандартных ML-подходах:

- Ridge;
- RandomForest;
- ExtraTrees;
- GradientBoosting;
- HistGradientBoosting;
- LightGBM / XGBoost / CatBoost, где это было доступно.

Первые submission дали score в районе 300+, после чего стало понятно, что основной прирост качества можно получить через ансамбли и отдельную работу с `SI`.

---

## Работа с SI

`SI` оказался самым сложным таргетом. Прямое предсказание SI моделью давало нестабильные значения и тяжёлый хвост.

Мы проверили несколько вариантов:

- полное предсказание `SI` отдельной моделью;
- частичный overlay SI-модели;
- использование формулы `SI = CC50 / IC50`;
- смешивание модельного SI и формульного SI;
- сглаживание и ограничение хвоста.

Наиболее устойчивым оказался вариант:

```text
SI_final = 0.30 * SI_model + 0.70 * (CC50_pred / IC50_pred)
```

Эта версия стала основой для дальнейших улучшений.

---

## Target-wise stack и overlay

После стабилизации `SI` мы аккуратно улучшали только `IC50` и `CC50`.

Был построен target-wise stack из нескольких моделей и трансформаций target. Сам по себе stack не стал лучшим решением, но небольшое подмешивание его предсказаний к сильной версии улучшило результат.

Затем был добавлен adversarial weighted overlay для `IC50` и `CC50`. `SI` при этом оставляли из уже стабилизированной версии, потому что пересчёт SI после каждого изменения IC50/CC50 часто ухудшал leaderboard.

---

## Финальная версия

Лучший официальный submission до дедлайна:

```text
v34_adv_weighted_ic50_020_cc50_030_keep_si.csv
```

Score:

```text
269.39668
```

Финальная логика:

```text
IC50 = 0.80 * base_IC50 + 0.20 * adv_IC50
CC50 = 0.70 * base_CC50 + 0.30 * adv_CC50
SI = base_SI
```

Где `base_SI` - это стабилизированная версия через смесь SI-модели и формулы `CC50 / IC50`.

---

## Вывод

В этой задаче лучше всего сработал не один конкретный алгоритм, а последовательное улучшение решения:

- сначала получили рабочий baseline;
- потом нашли слабое место - `SI`;
- стабилизировали `SI` через доменную формулу;
- после этого аккуратно улучшали `IC50` и `CC50`;
- в финале использовали небольшие overlay, не ломая уже найденное хорошее распределение `SI`.

Такой подход позволил снизить score с первых baseline-значений около 305 до финального официального результата 269.39668.

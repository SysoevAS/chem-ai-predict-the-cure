# Reports

В этой папке лежат итоговые материалы по аналитике и экспериментам.

## Файлы

- `final_solution_description.md` - подробное описание итогового решения.
- `experiments.md` - история основных экспериментов и Kaggle submission.
- `submission_history.csv` - таблица submission с score.
- `team_work_report.md` - краткое описание командной работы и принятых решений.

## Как использовать

Эти файлы можно читать независимо от ноутбуков. Они нужны, чтобы проверяющий мог быстро понять:

1. как мы шли от baseline к финальному решению;
2. почему отдельно работали с `SI`;
3. какие submission давали улучшение;
4. какой файл был финальным официальным кандидатом.
